# 이창민 (Lee Chang Min)

컴퓨터공학을 전공하는 학부생입니다. 시스템이 동작하는 원리를 직접 구현해 보며
이해하는 것을 좋아하고, 공공데이터를 다루는 일에 관심이 있습니다.

**공기업 전산직 · 데이터 직무**를 목표로 전공 기초와 실무 역량을 함께 쌓고 있습니다.

- 🎓 컴퓨터공학과 3학년 재학 중 (2028년 졸업 예정)
- 📜 정보처리기사 취득 준비 중
- 🌱 운영체제 · 자료구조 · 데이터베이스를 중심으로 전공 기초를 다지는 중
